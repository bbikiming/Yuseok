# 전략 명세: Puddle Rebound

웅덩이(급락 후 저점 지지·반등) 구간을 탐지해 +0.5~1.0% 단기 반등을 노리는 전략의
구현 명세. PRD §6 을 "코드로 옮길 수 있는" 수준으로 구체화.

## 용어
- **웅덩이(puddle)**: 단기 급락 후 매도세가 약해지고 저점이 지지되며 거래량이 회복되는 구간.
- **드롭 윈도(drop window)**: 급락 여부를 보는 직전 N분 구간.
- **반등 캔들**: 직전 저점 이후 양봉 전환된 1분봉.

## 입력 데이터 (한 종목, 한 시점)
| 출처 | 사용 |
|---|---|
| `prices` | 현재가, 등락률 |
| `candles(1m)` + resample(3m/5m) | OHLCV, 이동평균, 저점/고점 |
| `orderbook` | 스프레드, 매수/매도 잔량 비율 |
| `trades` | 최근 체결가 흐름, 매도호가 체결 비중(체결강도 근사) |
| `stocks/warnings` | VI/투자경고 등 제외 트리거 |
| `market-calendar` | 장 세션 판단 |

## 진입 후보 조건 (C1~C10) — 구현 정의
`puddle.require_*` 플래그로 on/off. 만족 개수 기반 점수화.

| ID | 정의(계산식 가이드) | 파라미터 |
|---|---|---|
| C1 | drop_window 내 (max_high → 현재가) 하락률 ≤ min_drop_rate | `drop_window_minutes`, `min_drop_rate` |
| C2 | 현재가 > 직전 저점 (저점 즉시 이탈 아님) | 직전 N분 최저가 |
| C3 | 하락 구간 거래량이 직전 평균 대비 감소 (매도세 둔화) | 거래량 배율 임계 |
| C4 | 반등 1분봉 거래량 > 직전 평균 (거래량 회복) | `require_volume_recovery` |
| C5 | 현재가 ≥ 1분봉 단기 MA(예: 5MA) | MA 기간 |
| C6 | 현재가 > 직전 1~3분 고점 (단기 돌파) | lookback 분 |
| C7 | 스프레드율 ≤ 임계 | `require_orderbook_stable`, max_spread_rate |
| C8 | 매도호가 체결 비중 증가 (적극 매수) | trades 분석 |
| C9 | 지수 대용 종목이 급락 중 아님 | 대용 종목(예: KODEX 200) |
| C10 | 장 시작 직후/마감 직전 아님 | 세션 시작+M분 ~ 종료-M분 |

## 제외 조건 (E1~E10)
하나라도 해당하면 후보에서 제외(점수와 무관하게 SKIP).

| ID | 정의 | 데이터 |
|---|---|---|
| E1 | 지수 대용 ETF 5분봉 급락 중 | candles(대용) |
| E2 | 전고점 돌파 실패 후 재하락 | candles |
| E3 | 스프레드 과대 | orderbook |
| E4 | 거래량 큰데 가격 정체 | candles+trades |
| E5 | 당일 고점권에서 하락 시작 | 당일 고가 대비 위치 |
| E6 | 최근 N분 내 같은 종목 손절 발생 | paper_trades/포지션 이력 |
| E7 | 일일 손실 한도 근접 | risk 상태 |
| E8 | API 오류/데이터 누락 | 수집 결과 |
| E9 | 저유동성(체결 희박) | trades 빈도/거래대금 |
| E10 | 장 운영시간 아님 | calendar |

## 점수화 (puddle_score, 0~100)
초기에는 단순 가중합으로 시작(모델 이전):
```
score = Σ(만족한 Cn 가중치)  →  0~100 정규화
```
- 가중치는 `strategy.yaml` 로 외부화(튜닝 대상). 초기값은 균등 후 데이터로 조정.
- `entry.min_puddle_score` 이상 + 제외조건 없음 → 진입 후보.
- AI 점수(`ai_score`)는 별도(§AI). `entry.min_ai_score` 미만이면 SKIP(allow_without_ai=false 시).

## 청산 룰 (Exit) — paper/실거래 공통
진입가 기준 비율(`exit.*`):
- **TP1** +0.5%: 1차 익절(부분 또는 알림)
- **TP2** +0.8~1.0%: 전량 익절
- **SL** -0.4~0.7%: 손절
- **시간청산** `max_hold_minutes` 초과 시 시장가/현재가 청산 → TIMEOUT

판정 우선순위(같은 봉 내 TP·SL 동시 도달 모호성):
- paper 단계에서는 보수적으로 **SL 우선**(불리하게) 가정하거나, `trades`(틱) 순서로 판정.
- 1분봉만으로 판정 시 고가·저가 도달 순서를 알 수 없으므로 결과를 `WEAK_*`로 보정 고려.

## 결과 라벨 (paper_trades.result)
| 라벨 | 정의 |
|---|---|
| WIN | TP가 SL보다 먼저 도달 |
| LOSS | SL가 TP보다 먼저 도달 |
| TIMEOUT | 보유시간 내 둘 다 미도달 |
| WEAK_WIN | +0.3~0.5% 약익절/본전 청산 |
| INVALID | 데이터 누락 등 평가 불가 |

## 튜닝 루프
일일 리포트(§13) → 잘 먹힌/실패 조건 분석 → `strategy.yaml` 가중치·임계 조정 →
다음 거래일 반영. 검증 통과(PRD §18.3) 시에만 실거래 승격.
