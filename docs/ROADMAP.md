# 로드맵

PRD §17 의 버전 계획. 각 버전은 이전 버전 검증 후 진행.

## v0.1 — CLI 가상매매 (MVP) 🎯 현재 목표
실주문 없이 웅덩이 탐지 + 가상매매 로그 축적.
- 프로젝트 초기화 / API 인증 / 관심종목 관리 ✅(골격)
- 현재가·캔들·호가 수집 → SQLite
- 웅덩이 탐지 (룰 기반 점수)
- 가상매매 + WIN/LOSS/TIMEOUT 라벨
- 일일 마크다운 리포트
- 제외: 실주문 / AI 학습 / 자동매매 / UI

## v0.2 — AI 점수화 & 학습
- feature/label builder, 모델 학습·평가
- 신호별 성공확률 출력, AI 점수 구간별 성과 리포트

## v0.3 — 반자동 주문
- 매수가능금액 조회·수량 계산
- 사용자 승인(`approve`) 후 주문, 체결 확인, 포지션 감시, 수동 청산

## v0.4 — 제한적 자동 익절/손절
- 실진입 후 자동 익절·손절·시간청산
- 일일 손실 한도, 긴급정지(kill)

## v0.5 — 제한적 자동진입
- 모델 게이트 통과 신호만 소액 자동진입
- 자동매매 리포트, 성능 저하 시 자동 비활성화

## 그 이후 (PRD §22)
- macOS 앱화(Tauri/React) — CLI 백엔드 유지
- 외부 데이터(지수/ETF 필터, 공시, 환율/선물)
- 전략 확장(돌파, VWAP 회복, 장초반 변동성 등)

## 자동매매 승격 게이트 (PRD §18.3)
v0.3+ 에서 auto 허용 전 모두 만족해야 함:
- 최근 20거래일+ 데이터, 신호 100+/진입 50+
- 비용 반영 후 기대값 양수, 승률 55%+, 최대 연속손실 한도 이하
- 최근 5거래일 성능 급락 없음, 사용자 수동 활성화
